Object Renamer Privacy Policy

Publisher: Oliver Wackenreuther
Effective date: November 6, 2026

Application data

Object Renamer does not collect, transmit, sell, rent, or share personal information, drawing information, named-object information, usage information, telemetry, or analytics.

It reads layer, block, dimension-style, linetype, table-style, and text-style information from the active AutoCAD drawing and processes rename instructions locally solely to perform user-requested operations. It does not use advertising, tracking, cloud processing, or third-party SDKs that receive application data.

Local storage

Object Renamer does not create application logs or automatically retain drawing information. If the user selects Save Script, the script is written only to the file and location selected by the user.

External links and support

Optional GitHub and LinkedIn links open only when selected, and no drawing information is sent by Object Renamer. Information independently processed by Autodesk for Marketplace access, downloads, accounts, or AutoCAD is governed by Autodesk's policies and is not received by Object Renamer.

Object Renamer does not share application or drawing data with third parties because it does not collect or transmit that data. No consent or consent-withdrawal mechanism is required for application-data processing because no such collection occurs.

Information voluntarily supplied for support is used only to respond to or diagnose the request, retained only as reasonably necessary, and not sold, rented, shared for advertising, or used for profiling. Users should remove confidential information from support materials. A user may request deletion of personal information voluntarily supplied for support by emailing owackenreuther@gmail.com.

Changes and contact

This policy will be updated before a future version begins collecting or transmitting application data. Privacy questions and deletion requests may be sent to owackenreuther@gmail.com. Technical issues may also be submitted through the Object Renamer support page.
