# Object Renamer Privacy Policy

**Publisher:** Oliver Wackenreuther  
**Effective date:** November 6, 2026

Object Renamer does not collect, transmit, sell, rent, or share personal information, drawing information, named-object information, usage information, telemetry, or analytics.

The application reads layer, block, dimension-style, linetype, table-style, and text-style names and related display properties from the active AutoCAD drawing. It processes rename instructions locally solely to perform actions requested by the user. It does not require a publisher account and does not use advertising, tracking, cloud processing, or third-party SDKs that receive application data.

Object Renamer does not create application logs or automatically retain drawing information outside the active drawing. If the user selects **Save Script**, the script is written only to the file and location selected by the user. Optional GitHub and LinkedIn links open only when selected; Object Renamer does not send drawing information to those sites.

Information independently processed by Autodesk for Marketplace access, downloads, accounts, or AutoCAD is governed by Autodesk's policies and is not received by Object Renamer.

Object Renamer does not share application or drawing data with third parties because it does not collect or transmit that data. No consent or consent-withdrawal mechanism is required for application-data processing because no such collection occurs.

If a user voluntarily contacts the publisher, information supplied by the user is used only to respond to or diagnose the request, retained only as reasonably necessary, and not sold, rented, shared for advertising, or used for profiling. Users should remove confidential information before supplying support materials. A user may request deletion of personal information voluntarily supplied for support by emailing **owackenreuther@gmail.com**.

This policy will be updated before any future version begins collecting or transmitting application data. Privacy questions and deletion requests may be sent to **owackenreuther@gmail.com**. Technical issues may also be submitted through the [Object Renamer support page](https://github.com/OliversDev/Object-Renamer-for-AutoCAD/issues).
